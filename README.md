# 李老师工作台（静态站）

单文件应用：`index.html` 即工作台本体（3.2MB，全内联，无外部依赖）。

- `index.html` —— 主页面（老师工作台）
- `tb.html` —— 与 index.html 相同，供旧书签 `/tb.html` 继续可用
- `p.html` —— **家长查询页**，入口 `p.html?k=<8位码>`，按码只加载该孩子那份数据
- `kid_<码>.json` —— 每个孩子一份（姓名、更新时间、作业等级、积分小计），共 51 份
- `404.html` —— 未知路径跳回首页
- `.nojekyll` —— 关闭 Jekyll 处理（必须有）

## 自动部署
GitHub Pages 已开启「Deploy from a branch → main → / (root)」，**推送即自动部署**，无需任何手动操作。

改版：
```bash
cp -f 新源码.html index.html && cp -f 新源码.html tb.html
git add -A && git commit -m "说明改动" && git push origin main
```

## 家长查询页怎么更新数据
1. 用最新云同步备份跑 `/workspace/家长查询码/regen_kid.py` → 覆盖本目录 `kid_*.json`
2. `python3 deploy.py "更新家长查询数据"` 推送
3. 二维码**不用重印**（码不变，只换数据）

## ⚠️ 首次在新域名打开后
Gitee 云同步配置存在浏览器 localStorage（按域名隔离），换域名后需在「同步设置」重新粘贴一次设置码，否则读不到云端数据。

## 安全（重要，别误改）
- 工作台本体不含学生数据，数据都在 **私有** Gitee 仓库 `work`（绝不可转公开）。
- 本仓库**公开**，`kid_*.json` 是唯一例外：它确实是含姓名的静态文件，靠 8 位随机码定位（不在任何页面挂链接，仓库里也不列索引）。
  若哪天要求更严，把这 51 个文件删掉、`p.html` 一并删掉即可，家长码随之作废（不影响工作台）。
- 除 `kid_*.json` 外，**不要**再往本仓库提交含学生姓名、学号、成绩、家长联系方式的文件。
